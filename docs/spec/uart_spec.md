# UART送信（uart_tx）仕様 v1

> 日1（2026-11-04）に決めた仕様。ポートの名前、busy、`start`の扱いは私（Claude）の案で、書籍の記述ではない。
> 目的：RTL → 論理合成 → STA → DFT → 配置配線 → 電力 → DRC/LVS を、この1つの設計で通す。

## ポート

| 名前 | 向き | 幅 | 意味 |
|---|---|---|---|
| clk | 入力 | 1 | クロック |
| rst_n | 入力 | 1 | 非同期リセット（Lowで有効）。`tx = 1`、`busy = 0` になる |
| start | 入力 | 1 | 送信開始の要求 |
| data | 入力 | 8 | 送るデータ |
| tx | 出力 | 1 | 送信線。待機中は `1` |
| busy | 出力 | 1 | 送信中は `1` |

パラメータ：`BIT_CLKS`（1ビット分のクロック数。既定値 4。実機に近づけるときに大きくする）

## 動作

- 待機中（`busy = 0`）に `start = 1` のクロックの立ち上がりを受けたら、`data` を取り込む。
- 次のサイクルから送信する。順に、スタートビット（`tx = 0`）、`data[0]` 〜 `data[7]`（下位から）、ストップビット（`tx = 1`）。各ビットは `BIT_CLKS` クロック分。
- 送信中（`busy = 1`）の `start` は無視する。
- ストップビットが終わったら、待機に戻る（`busy = 0`、`tx = 1`）。
- `start` は1サイクルだけ `1` にする前提。
- パリティは付けない。

## 内部の部品（日1の問5で確認したもの）

- ビット番号 k のカウンタ：4ビット、`0`〜`9`（10通り）
- 1ビット分のクロックを数えるカウンタ：`0`〜`BIT_CLKS-1`、一周したら k を `+1`（縦続接続の考え方）
- 送信中だけ数える（イネーブル付カウンタの考え方）
- 取り込んだ `data` を保持するレジスタ（8ビット）
- `tx` は、レジスタの出力として出す（10-5のスパイクフリーの考え方）

## 確認する波形（BIT_CLKS = 4、data = 8'b10110010）

送る順は `0, 1, 0, 0, 1, 1, 0, 1`。`tx` は次のとおり。

| k | 内容 | tx | クロック番号 |
|---|---|---|---|
| 0 | start | 0 | 1〜4 |
| 1〜8 | data[0]〜data[7] | 0,1,0,0,1,1,0,1 | 5〜36 |
| 9 | stop | 1 | 37〜40 |
